## Exactly what remains unfinished

No complete new regression suite for this pass was written. The archive fixture dependencies were installed but adversarial fixtures/tests are still missing. Re-run against the final snapshot, including concurrent quota/token consumers, forced outbox failure, private scanner errors/timeouts, stream limits and cleanup, and all owner boundaries.
2. **Encryption rollout blocker:** existing outbox messages use the old session-derived key; the new decryptor does not migrate or decode them. Design and test a safe migration/reissuance procedure. In development/test, omitted dedicated keys currently generate process-local keys, which is unsuitable for durable mail across restarts. Production requires both keys, but development persistence still needs correction. Document key generation/rotation without exposing values.
3. **Authentication/session completion:** expired-session password reauthentication calls an endpoint that itself requires a live session, so automatic in-editor session recovery is incomplete. Trust-choice propagation through all passkey and device-completion paths needs verification. Session cookies still have a 90-day max-age while the database enforces the selected/temporary expiry. Session listing does not fully apply idle/epoch filters. Password-change session issuance and some device/passkey actions still span separate database/Redis operations; audit crash/race semantics. Recovery codes lack configurable expiry. Registration duplicate responses still reveal account existence. Account-discovery response timing has not been evaluated.
4. **Recovery notifications and edge cases:** exercise both unverified reset paths all the way through device approval. Review verification/change/removal notification delivery to all established verified channels and all stale-token invalidations. Primary change duplicate-email races and generic errors need tests. Discovery currently returns a masked address per one-use link; multi-account selection/recovery UX needs validation.
5. **Rate limiting/CAPTCHA:** registration and adaptive login hooks exist, but adaptive repeated reset/discovery CAPTCHA is not complete.
